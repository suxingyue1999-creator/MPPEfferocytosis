# MPP Efferocytosis

Private staging repository for the analysis code accompanying the pediatric
Mycoplasma pneumoniae pneumonia efferocytosis study.

## Current Status

This repository contains preparation documentation only. Original analysis
scripts have not yet been imported because their external source drive is not
mounted. It is not a complete reproducibility package and must not be cited as
an available code resource in a manuscript or submission form.

No clinical records, sequencing data, proteomic data, patient metadata,
manuscripts, credentials, or access tokens are included.

## Release Requirements

1. Recover the original scripts used to generate the submitted results.
2. Check script provenance and correspondence with the reported analyses.
3. Remove credentials, clinical identifiers, identifying metadata, and local
   private paths without changing the analytical methods.
4. Document required inputs, software versions, execution order, and outputs.
5. Verify the scripts to the extent allowed by the available input datasets and
   disclose any remaining reproducibility limitations.
6. Confirm code ownership and applicable licensing before release.
7. Publish a fixed code version and verify access without authentication before
   adding the code URL to the manuscript or submission form.

## Data Access

A code repository does not replace the study's data-deposition obligations.
Clinical transcriptomic and proteomic datasets require appropriate repositories
and access arrangements consistent with consent, ethics approval, and
institutional requirements. Data access remains unresolved at this stage.
